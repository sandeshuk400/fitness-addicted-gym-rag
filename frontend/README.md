# Frontend

Planned for Phase 1: React + TypeScript (Vite) with role-based portals:

- **Member:** profile, subscription status, class booking, AI assistant chat
- **Trainer:** assigned members, workout / diet plans (AI-assisted drafts)
- **Staff:** check-in desk, member lookup, renewals
- **Admin:** dashboard (revenue, active members, churn, peak hours), knowledge-base upload and re-index

The backend exposes a REST API documented with Swagger UI at `/swagger-ui.html`.
